# Local Proctoring Student — portable Windows x64

Double-click the portable student EXE. It verifies and extracts its internal application to stable per-user storage, then displays **Checking exam security**. A valid matching recovery audit is reused; otherwise the existing 21-check native recovery audit runs automatically without shortcut suppression. Allow approximately 2–5 minutes, leave the keyboard and temporary windows available, and avoid remote control during this check. Join opens only after a valid completed report and successful audit process exit. This is one downloadable file, not one process. Do not run private executables directly.

No Python, Node, npm, model downloads or manual TOML editing is needed. Enter the teacher server address, verify it, then enter the exam code and your institutional student details. Complete the required consent and readiness checks. Localhost HTTP is permitted only for literal loopback addresses; other servers require trusted HTTPS.

This edition contains Electron, Python, helper/guardian, CPU vision, YOLO/MediaPipe, PDF generation, evidence synchronization, event snapshots, audio evidence and screen-viewing resources. **DeepFace identity/liveness is not included. Exams requiring either are rejected, not downgraded.** Source builds retain their optional face runtime.

Teachers set a private 6–12 digit PIN under the dashboard's **Security → Protection PIN**. Connected pause/resume/end authorization requires the teacher server. No shared PIN or teacher verifier is distributed. Emergency release **Ctrl+Shift+Alt+Q** does not depend on the PIN or network.

This distribution accepts ONLY Protected Mode teacher exams. There is no student mode switch. No keyboard or focus restrictions activate on Join. Protected Start still requires admission, consent, devices, reference/calibration, a configured teacher PIN, matching recovery validation and helper/guardian readiness. Historical source or different-package audits cannot authorize this package. **Packaged Protected Mode is UNVALIDATED: do not launch this new EXE until its first native check is separately authorized.** No active shortcut fixture runs automatically.

Failures block Join and retain diagnostics. Close the app, address the cause, then reopen and explicitly confirm Retry. There is no automatic retry after failure or interruption. A simultaneous second launch is rejected. Audit history and process-exit receipts are under Student/audits/history; startup-current.json is only the replaceable prerequisite copy. Reuse requires the same EXE, extracted runtime, machine, trusted configuration, protection policy and a report younger than 24 hours.

Resources live under `%LOCALAPPDATA%\LocalProctoring\Portable\builds`; trusted per-build defaults and sessions under `%LOCALAPPDATA%\LocalProctoring\Student`; the encrypted connected journal under `%LOCALAPPDATA%\LocalProctoring`. Do not delete these directories while evidence is pending. Updates preserve data and reject unfinished attempts from a different build. Unexpected changes to installed resources or default configuration block startup. Packaged startup requires exact trusted defaults even when an explicit configuration path is supplied.
